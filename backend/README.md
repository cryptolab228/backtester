# Backend - Backtester V2

Серверная часть системы бэктестинга с автоматическим запуском всех сервисов.

## 🚀 Быстрый запуск

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки (автозапуск всех сервисов)
```bash
npm run dev
```

**Система автоматически:**
- ✅ Запустит PostgreSQL (если не запущен)
- ✅ Запустит Redis (если не запущен)
- ✅ Создаст базу данных и таблицы
- ✅ Запустит сервер на порту 5000

## 📋 Доступные команды

```bash
# Разработка с автозапуском сервисов
npm run dev

# Сборка для production
npm run build

# Запуск production версии
npm start

# Очистка
npm run clean

# Переустановка зависимостей
npm run reinstall
```

## 🏗️ Архитектура

### Новая система запуска (по аналогии с cryptolab)
- **Автоматический запуск сервисов** - PostgreSQL и Redis запускаются автоматически
- **Упрощенное подключение к БД** - через middleware в каждый запрос
- **Автоматические миграции** - таблицы создаются при первом запуске
- **Graceful shutdown** - корректное завершение всех сервисов

### Структура файлов
```
src/
├── app.ts                        # Главный файл приложения
├── middleware/
│   ├── PostgreSQL.ts            # Подключение к БД (как в cryptolab)
│   └── sql/
│       └── createTables.sql     # SQL схема базы данных
├── services/
│   ├── PostgreSQLManager.ts     # Автозапуск PostgreSQL
│   └── RedisManager.ts          # Автозапуск Redis
├── modules/                     # Бизнес-модули
├── routes/                      # API роуты
└── utils/                       # Утилиты
```

### Мульти-Бектестер (Портфельный Бектестер) ✅ ЗАВЕРШЕН

#### 🚀 Основные Возможности
- **Портфельный бектест:** Одновременное тестирование стратегии на нескольких торговых парах
- **Общий капитал:** Управление единым капиталом портфеля с реинвестированием
- **Приоритизация сигналов:** Сигналы приоритизируются по силе (`signalStrength`)
- **Портфельные метрики:** Sharpe Ratio, среднее/пиковое количество одновременных сделок
- **WebSocket уведомления:** Реальные обновления о статусе бектестинга

#### 📡 API Endpoints
```bash
# Обычный бектест (одна пара)
POST /api/backtest/run

# Портфельный бектест (множественные пары)
POST /api/backtest/portfolio/run
```

## 🐛 Устранение неполадок

### PostgreSQL не запускается
1. Убедитесь что PostgreSQL установлен в системе
2. Проверьте свободность порта 5432
3. Система попробует запустить автоматически

### Redis не запускается  
1. Запустите `npm run setup:redis` в корне проекта
2. Проверьте свободность порта 6379

### Проблемы с зависимостями
```bash
npm run reinstall
```

### Логи и отладка
Логи выводятся в консоль и сохраняются в:
- `logs/combined.log` - все логи
- `logs/error.log` - только ошибки

## 🔄 Миграция с предыдущей версии

Если у вас была предыдущая версия с Docker или сложными скриптами:

1. Остановите все старые сервисы
2. Обновите зависимости: `npm install`
3. Запустите новую версию: `npm run dev`

Система автоматически создаст все необходимые таблицы.
