# Объяснение: Почему общий PnL ≠ сумме PnL по парам

## 📊 ВАШ ПРИМЕР

### Результаты с экрана:
```
Общий PnL:      $3,259.10   (32.59% ROI)
Начальный:      $10,000

PnL по парам:
BTCUSDT:        $829.22
XRPUSDT:        $2,631.10
SOLUSDT:        $2,283.27
ETHUSDT:        $1,468.92
───────────────────────
СУММА:          $7,212.51   ← ПОЧЕМУ БОЛЬШЕ?
```

---

## 🎯 ПРИЧИНА

Каждая пара показывает PnL **КАК БУДТО** весь капитал ($10,000) принадлежит только ей.

### Пример расчета:

**Реальность (портфель):**
```
T0: Капитал $10,000
  → BTCUSDT открывает сделку, блокирует $2,500
  → Доступно: $7,500

T1: Доступно $7,500
  → XRPUSDT открывает сделку, блокирует $2,000
  → Доступно: $5,500

T2: BTCUSDT закрывается с прибылью +$200
  → Освобождается: $2,500
  → Капитал: $5,500 + $2,500 + $200 = $8,200

ИТОГО: +$200 на общем капитале
```

**Расчет PnL для BTCUSDT отдельно:**
```
"Если бы BTCUSDT торговал всеми $10,000"
→ Размер позиции был бы больше
→ PnL был бы $829.22 вместо $200
```

**Расчет PnL для XRPUSDT отдельно:**
```
"Если бы XRPUSDT торговал всеми $10,000"
→ Размер позиции был бы больше
→ PnL был бы $2,631.10
```

---

## 📐 МАТЕМАТИКА

### Портфельный режим (правильный):
```
Капитал ДЕЛИТСЯ между активными сделками
→ Каждая пара торгует своей долей
→ Общий PnL = реальный результат торговли
```

### Метрики по парам (для анализа):
```
"Что если бы пара торговала ВСЕМ капиталом?"
→ Гипотетический результат
→ Сумма ≠ реальность
```

```
НО это НЕ реальный результат!
```
