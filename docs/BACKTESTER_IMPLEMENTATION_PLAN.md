### 3.3.1 Ошибка переполнения числового поля базы данных ✅ **ИСПРАВЛЕНО!**

#### A. Проблема
- **Ошибка**: `Error saving candles for SLP-USDT-SWAP (1d): numeric field overflow`
- **Затронутые пары**: CAT-USDT-SWAP, DOGS-USDT-SWAP, FLOKI-USDT-SWAP, SLP-USDT-SWAP
- **Причина**: DECIMAL(18,8) недостаточно для:
  - Мем-токенов с очень малыми ценами (0.00000001)
  - Токенов с большими объемами (миллиарды единиц)

#### B. Решение ✅
- [x] **Обновлена модель Candle.ts**
  - Поля цен: `DECIMAL(18,8)` → `DECIMAL(28,18)` 
  - Поля объемов: `DECIMAL(18,8)` → `DECIMAL(30,8)`
  - Поддержка 18 знаков после запятой для микро-цен
  - Поддержка 30 разрядов для больших объемов

- [x] **Создана SQL миграция** (`backend/migrations/update_candles_precision.sql`)
  - Безопасное обновление структуры таблицы
  - Транзакционное выполнение
  - Добавлены комментарии к таблице

#### C. Техническая реализация ✅
```typescript
// Обновленные типы полей в Candle.ts
@Column({ type: 'decimal', precision: 28, scale: 18 }) // Цены
@Column({ type: 'decimal', precision: 30, scale: 8 })  // Объемы
```

```sql
-- SQL миграция
ALTER TABLE candles 
  ALTER COLUMN open TYPE DECIMAL(28,18),
  ALTER COLUMN high TYPE DECIMAL(28,18),
  ALTER COLUMN low TYPE DECIMAL(28,18),
  ALTER COLUMN close TYPE DECIMAL(28,18),
  ALTER COLUMN volume TYPE DECIMAL(30,8),
  ALTER COLUMN volume_quote TYPE DECIMAL(30,8);
```
