## I. Проблема Различий в Данных между API и БД ✅ **ИСПРАВЛЕНО**

**Статус: РЕШЕНО** ✅

### I.1 Описание Проблемы

**Обнаружено**: При выполнении идентичных бэктестов с одинаковыми параметрами:
- **Тест с загрузкой из API**: 1473 сделки
- **Тест с загрузкой из БД**: 1300 сделок  

**Корневая причина**: Различия в типах данных между API и БД приводят к разным вычислениям в стратегии.

### I.2 Технические Детали Проблемы

#### A. Проблемы с Типами Данных
1. **Decimal поля из БД возвращаются как strings**:
   ```sql
   -- В БД: DECIMAL(28,18) 
   -- TypeORM возвращает: "123.456789" (string)
   -- API возвращает: 123.456789 (number)
   ```

2. **BigInt timestamp обрабатывается некорректно**:
   ```sql
   -- В БД: BIGINT
   -- TypeORM может возвращать: "1641067200000" (string)
   -- API возвращает: 1641067200000 (number)
   ```

#### B. Последствия для Стратегии
- **Арифметические операции** с string vs number дают разные результаты
- **Условия сравнения** в стратегии могут работать некорректно
- **Временные вычисления** могут провалиться при создании Date объектов

### I.3 Решения ✅ **РЕАЛИЗОВАНЫ**

#### A. Корневая причина найдена ✅
**Проблема:** `dataService.getCandles()` использовал `createQueryBuilder().getMany()`, который **НЕ применяет ValueTransformers** в TypeORM.

#### B. Исправление QueryBuilder ✅ 
Заменен QueryBuilder на `Repository.find()` в `dataService.ts`:
```typescript
// БЫЛО (НЕ работает с ValueTransformers):
const query = this.candleRepository.createQueryBuilder('candle')
const candles = await query.getMany();

// СТАЛО (работает с ValueTransformers):
```

#### C. ValueTransformers в модели Candle ✅
```typescript
// Трансформер для decimal полей
const numberTransformer: ValueTransformer = {
  to: (value: number) => value,
  from: (value: string) => parseFloat(value)
};

// Трансформер для timestamp
const timestampTransformer: ValueTransformer = {
  to: (value: number) => value,
  from: (value: string | number) => {
    if (typeof value === 'string') {
      const parsed = parseInt(value, 10);
      return isNaN(parsed) ? 0 : parsed;
    }
    return value;
  }
};

// Применено к полям:
@Column({ 
  type: 'decimal', 
  precision: 28, 
  scale: 18,
  transformer: numberTransformer
})
open!: number;

@Column({ 
  type: 'bigint',
  transformer: timestampTransformer
})
timestamp!: number;
```
