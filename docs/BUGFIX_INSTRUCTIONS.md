# Инструкции по Исправлению Критических Ошибок

## Проблемы выявленные в логах

### 1. Ошибка переполнения числового поля базы данных
**Лог**: `Error saving candles for SLP-USDT-SWAP (1d): numeric field overflow`

### 2. Отсутствие данных от API для некоторых пар  
**Лог**: `No candles fetched from API for SOON-USDT-SWAP`

## Решения

### Исправление 1: Увеличение точности DECIMAL полей

#### Проблема
- DECIMAL(18,8) недостаточно для мем-токенов с очень малыми ценами
- Недостаточно для токенов с большими объемами (миллиарды единиц)

#### Решение
1. **Обновлена модель Candle.ts**:
   - Поля цен: `DECIMAL(18,8)` → `DECIMAL(28,18)`
   - Поля объемов: `DECIMAL(18,8)` → `DECIMAL(30,8)`

2. **Создана миграция SQL**: `backend/migrations/update_candles_precision.sql`

#### Применение исправления
```bash
# 1. Остановить приложение
npm run stop

# 2. Применить миграцию
cd backend
psql -d backtester_db -f migrations/update_candles_precision.sql

# 3. Перезапустить приложение  
npm run start
```

### Исправление 2: Валидация торговых пар перед запросом данных

#### Проблема
- Некоторые пары не существуют на OKX
- Лишние запросы к API для несуществующих пар
- Неинформативные ошибки

#### Решение
1. **Добавлена функция `validateTradingPair()`** в okxService.ts
2. **Предварительная проверка** существования пары перед запросом данных
3. **Улучшенное логирование** для несуществующих пар

#### Применение исправления
```bash
# Автоматически применяется при перезапуске приложения
npm run restart
```
