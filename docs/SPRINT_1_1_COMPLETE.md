## 📝 Примеры Использования

### Простой Пример

```typescript
import { leverageManager } from '@/modules/futures';

// Рассчитать цену ликвидации
const liqPrice = leverageManager.calculateLiquidationPrice(
  50000,  // entry
  10,     // leverage
  'long'  // direction
);

console.log(`Ликвидация при: $${liqPrice}`);
```

### Комплексный Пример

```typescript
import {
  leverageManager,
  fundingManager,
  futuresPositionSizer
} from '@/modules/futures';

// 1. Расчет позиции
const position = futuresPositionSizer.calculatePositionSize(
  10000,  // balance
  2,      // risk %
  50000,  // entry
  48000,  // SL
  10      // leverage
);

// 2. Проверка ликвидации
const liqPrice = leverageManager.calculateLiquidationPrice(
  50000,
  10,
  'long'
);

// 3. Расчет funding
const fundingData = await fundingManager.getCurrentFundingRate(
  'BTCUSDT',
  'bybit'
);

console.log('Все данные:', { position, liqPrice, fundingData });
```
