## 📊 Как Работает

### **Алгоритм:**

```
1. Загрузить исторические данные (90 дней)
   └─> BTCUSDT, 1h timeframe

2. Сгенерировать все комбинации параметров
   └─> 4 × 4 × 4 × 3 = 192 варианта

3. Для каждой комбинации:
   ├─> Настроить futures профиль
   ├─> Запустить бектест
   ├─> Собрать метрики
   └─> Рассчитать комплексный score

4. Сортировать по score (от лучшего к худшему)

5. Вывести:
   ├─> Топ-10 результатов
   ├─> Статистику по всем комбинациям
   ├─> Рекомендации (лучшие параметры)
   └─> Сохранить JSON отчет
```

### **Scoring Formula:**

```typescript
score = 
  + totalPnlPercentage              // Прибыль (главное)
  + winRate * 0.5                   // Win rate
  + min(profitFactor * 10, 50)      // Profit factor
  - maxDrawdown * 2                 // Штраф за просадку
  + min(totalTrades / 10, 10)       // Бонус за сделки
  + effectiveROI * 0.2              // ROI с плечом
  + capitalEfficiency * 0.1         // Эффективность
  + avgDistanceToLiq * 0.5          // Расстояние до лик.
  - abs(netFunding) * 0.1           // Funding costs
  - liquidations * 1000             // СИЛЬНЫЙ штраф!
```
