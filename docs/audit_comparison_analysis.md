### 4️⃣ **Механизм закрытия сделки**

**Аудит A (строки 52-57):**
```
При закрытии:
- pnlRaw = (exitPrice - entryPrice) * size для long
- exitFee = exitPrice * size * tradingFeeRate
- pnlNet = pnlRaw - exitFee
- currentCapital += margin + pnlNet
```

**Аудит B (строки 299-333):**
```
// 1. Расчет PnL
pnl = (exitPrice - entryPrice) * size  // LONG
pnl = (entryPrice - exitPrice) * size  // SHORT

// 2. Комиссия на выход
exitFee = exitPrice * size * tradingFeeRate

// 3. Вычитание комиссии из PnL
pnl -= exitFee

// 4. РАЗБЛОКИРОВКА маржи
currentCapital += margin

// 5. Добавление PnL
currentCapital += pnl
```

**Вывод:** ✅ **СОВПАДАЕТ.** Логика идентична. Аудит B более структурирован.
