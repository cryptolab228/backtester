### ✅ ИСПРАВЛЕНО: Результаты исчезают после обновления страницы
**Проблема**: Запущенный тест не отображается на странице бэктестера после обновления страницы, но отображается при переходе на другие страницы без обновления.

**Причина**:
1. При восстановлении состояния функция `restoreActiveJobState()` очищала завершенные задачи из localStorage
2. При восстановлении режима бэктестера вызывалась `clearResults()`, удаляя все результаты из памяти

**Решение**:
1. Функция восстановления состояния теперь очищает только состояние активных задач, НЕ трогая результаты
2. Добавлена функция `restorePortfolioMode()` для безопасного восстановления режима
3. Улучшена диагностика с подробным логированием

**Статус**: ✅ Исправлено в версии от [текущая дата]
